OHLpkg 2.7.0 · Getting Started

Ontario Hockey League data, straight into R.

Retrieve complete HockeyTech player statistics, OHL and NHL draft histories, special-teams production, goalie data, schedules and game events in R. This guide introduces all 16 OHLpkg functions with practical examples.

Start here

The fastest way to understand OHLpkg is to retrieve a real dataset. Most workflows follow the same four-step pattern.

Step 1Choose a season
Step 2Retrieve data
Step 3Filter it
Step 4Analyze in R
library(OHLpkg)

# See every supported season
get_Seasons()

# Retrieve every active skater
players <- get_RawStats("2027 Season")

# Inspect the result
head(players)

The returned object is a regular R data frame, so you can immediately use base R, dplyr, ggplot2, Shiny, Tableau exports or whatever analysis workflow you already prefer.

Skater statistics

Choose between standardized skater statistics with get_RawStats(), minimum-games filtering with get_Stats(), or every source field with get_AllRawStats().

Raw vs. filtered statistics

Use get_RawStats() for active skaters with standardized names, PlayerID and PhotoURL. Use get_Stats() when you want a games-played cutoff (10 GP by default). 

# Every active skater
raw <- get_RawStats("2027 Season")

# Players with at least 10 GP
established <- get_Stats(
  season_name = "2027 Season",
  min_games = 10
)

# Same function, but include everyone
everyone <- get_Stats(
  season_name = "2027 Season",
  min_games = 0
)

All original API fields

New in 2.7.0: get_AllRawStats() preserves every column returned by the player-statistics feed under its original API name, including available faceoff fields. It does not rename or discard columns. 

all_raw <- get_AllRawStats("2027 Season")

# Explore all available source fields
names(all_raw)
nrow(all_raw)
ncol(all_raw)

# Find faceoff-related variables
grep("faceoff", names(all_raw), value = TRUE)

# Export if needed
write.csv(all_raw, "OHL_AllRawStats.csv", row.names = FALSE)

Original field availability varies by season. get_AllRawStats() supports the same optional team argument as the standardized skater-statistics functions.

Filter by team

Many OHLpkg functions accept a single team or a vector of teams. Use get_Teams() to confirm the exact team names first. 

get_Teams()

london <- get_Stats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)

two_teams <- get_Stats(
  season_name = "2027 Season",
  team = c("London Knights", "Oshawa Generals"),
  min_games = 0
)

Special-situation production

Analyze even-strength, power-play and short-handed production, plus penalty minutes. Specialized functions support optional team and minimum-games filtering. 

# Even-strength goals, assists and points
ev <- get_EVStats("2027 Season", min_games = 0)

# Power-play goals, assists and points
pp <- get_PPStats("2027 Season", min_games = 0)

# Short-handed production
sh <- get_SHStats("2027 Season", min_games = 0)

# Penalty minutes and penalty minutes per game
pim <- get_PIMStats("2027 Season", min_games = 0)

get_PPStats() includes PPG, PPA, PPP, PPP/G and PPP%. get_PIMStats() includes PIM and PIM/G. The even-strength and short-handed functions also include production rates and shares where supported.

Draft-eligible players and rookies

Two functions make it easy to isolate prospect groups without rebuilding age or rookie filters every time. 

# First-time NHL draft-eligible skaters
draft_class <- get_DYStats(
  season_name = "2027 Season",
  min_games = 0
)

# Players flagged as rookies in the OHL feed
rookies <- get_RKStats(
  season_name = "2027 Season",
  min_games = 0
)

Use get_PlayerInfo() when you need player IDs and biographical fields such as height, weight, birthdate and team information. 

player_info <- get_PlayerInfo("2027 Season")

head(player_info)

Player draft histories New in 2.7.0

get_DraftData() reads official OHL player profiles. Search by one or more player_id values, or select a season_name and optional team. Team and season searches use get_AllRawStats() to identify player IDs. 

# One player's official draft history
one_player <- get_DraftData(player_id = 9118)

# Multiple player IDs
players <- get_DraftData(player_id = c(9118, 9638))

# All available Peterborough Petes player IDs for a season
petes <- get_DraftData(
  season_name = "2027 Season",
  team = "Peterborough Petes"
)

# Export the team dataset directly
get_DraftData(
  season_name = "2027 Season",
  team = "Peterborough Petes",
  csv_file = "Peterborough_DraftData.csv"
)

Additional columns include PlayerID, Name, DOB, Pos, AcquisitionType, FreeAgent, ProfileURL and ProfileStatus.

Free-agent interpretation. FreeAgent = FALSE means an OHL, U18 or Import Draft selection was identified. TRUE means a successfully interpreted draft section lists no such selection. Unavailable or unrecognized records produce NA. NHL draft status does not determine OHL free agency. Profile scraping makes season-wide requests slower than feed-based functions; verify important classifications against official records.

Goalie statistics

Goaltenders have their own retrieval function and support the same basic team and minimum-games workflow. 

goalies <- get_GoalieStats(
  season_name = "2027 Season",
  min_games = 0
)

london_goalies <- get_GoalieStats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)

Schedules and game events

OHLpkg also lets you move from season-level statistics into individual games. Start with the schedule, then use a game's ID to retrieve its event feed. 

# Step 1: get the schedule
schedule <- get_Schedule()

# Step 2: find games with recorded scores
completed_games <- schedule[
  !is.na(schedule$HomeGoals) &
  !is.na(schedule$VisitorGoals),
]

# Step 3: choose a game ID
game_id <- completed_games$ID[1]

# Step 4: retrieve the play-by-play events
events <- get_GameEvents(game_id)

head(events)
Useful pattern: get_Schedule() gives you the bridge from league-level data to individual-game analysis.

Common problems

No players were returned

get_Stats() defaults to a minimum-games requirement. Early in a season, try min_games = 0.

I don't know the correct season or team name

get_Seasons()
get_Teams()

What is the difference between raw and all-raw statistics?

get_RawStats() standardizes a selected set of skater fields; get_AllRawStats() retains all original API fields, including any additional faceoff and shooting data provided by the source.

What's the difference between draft eligibility and draft history?

get_DYStats() identifies first-time NHL draft-eligible skaters using birthdates. get_DraftData() reads recorded selections and acquisition information from player profiles.

Why is draft retrieval slow or incomplete?

The function fetches profiles individually. Some pages may be missing, blocked or formatted differently. Check ProfileStatus and the original ProfileURL before relying on a classification.

I received an API or connection error

OHLpkg depends on externally maintained online data feeds. Temporary outages, network restrictions or feed changes can affect availability.

Something looks wrong

Open an issue on GitHub and include the function, season, filters, package version and complete error message.
