OHLpkg 2.6.0 · Getting Started

Ontario Hockey League data, straight into R.

OHLpkg provides a focused set of tools for retrieving skater, goalie, team, schedule, prospect and game-event data from the Ontario Hockey League. This guide takes you from installation to useful analysis without turning the documentation into a wall of function definitions.

Installation

Install the stable CRAN release once it is available:

install.packages("OHLpkg")
library(OHLpkg)

To install the current development version directly from GitHub:

if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}

remotes::install_github("NoahCornish/OHLpkg")
library(OHLpkg)
Live data package. OHLpkg retrieves information from online OHL data feeds, so an internet connection is required when requesting data.

Start here

The fastest way to understand OHLpkg is to retrieve a real dataset. Most workflows follow the same four-step pattern.

Step 1Choose a season
Step 2Retrieve data
Step 3Filter it
Step 4Analyze in R
library(OHLpkg)

# See every supported season
get_Seasons()

# Retrieve every active skater
players <- get_RawStats("2027 Season")

# Inspect the result
head(players)

The returned object is a regular R data frame, so you can immediately use base R, dplyr, ggplot2, Shiny, Tableau exports or whatever analysis workflow you already prefer.

Understanding seasons

OHLpkg names seasons by their ending year. Use get_Seasons() whenever you want to confirm a supported name or ID.

OHLpkg nameMeaning
"2027 Season"2026–27 regular season
"2026 Season"2025–26 regular season
"2026 Playoffs"2026 OHL playoffs
"2026 Pre-Season"2025–26 preseason
 
seasons <- get_Seasons()

head(seasons)

Skater statistics

There are two primary entry points for skater data: get_RawStats() and get_Stats().

Raw vs. filtered statistics

Use get_RawStats() when you want every active skater in the selected feed. Use get_Stats() when you want a games-played cutoff. 

# Every active skater
raw <- get_RawStats("2027 Season")

# Players with at least 10 GP
established <- get_Stats(
  season_name = "2027 Season",
  min_games = 10
)

# Same function, but include everyone
everyone <- get_Stats(
  season_name = "2027 Season",
  min_games = 0
)

Filter by team

Many OHLpkg functions accept a single team or a vector of teams. Use get_Teams() to confirm the exact team names first. 

get_Teams()

london <- get_Stats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)

two_teams <- get_Stats(
  season_name = "2027 Season",
  team = c("London Knights", "Oshawa Generals"),
  min_games = 0
)

Special-situation production

OHLpkg can separate even-strength and short-handed production so you can look beyond a player's raw point total. 

ev <- get_EVStats(
  season_name = "2027 Season",
  min_games = 10
)

sh <- get_SHStats(
  season_name = "2027 Season",
  min_games = 0
)

The specialized tables include rate and share statistics in addition to the underlying goal, assist and point totals.

Draft-eligible players and rookies

Two functions make it easy to isolate prospect groups without rebuilding age or rookie filters every time. 

# First-time NHL draft-eligible skaters
draft_class <- get_DYStats(
  season_name = "2027 Season",
  min_games = 0
)

# Players flagged as rookies in the OHL feed
rookies <- get_RKStats(
  season_name = "2027 Season",
  min_games = 0
)

Use get_PlayerInfo() when you need player IDs and biographical fields such as height, weight, birthdate and team information. 

player_info <- get_PlayerInfo("2027 Season")

head(player_info)

Goalie statistics

Goaltenders have their own retrieval function and support the same basic team and minimum-games workflow. 

goalies <- get_GoalieStats(
  season_name = "2027 Season",
  min_games = 0
)

london_goalies <- get_GoalieStats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)

Schedules and game events

OHLpkg also lets you move from season-level statistics into individual games. Start with the schedule, then use a game's ID to retrieve its event feed. 

# Step 1: get the schedule
schedule <- get_Schedule()

# Step 2: find games with recorded scores
completed_games <- schedule[
  !is.na(schedule$HomeGoals) &
  !is.na(schedule$VisitorGoals),
]

# Step 3: choose a game ID
game_id <- completed_games$ID[1]

# Step 4: retrieve the play-by-play events
events <- get_GameEvents(game_id)

head(events)
Useful pattern: get_Schedule() gives you the bridge from league-level data to individual-game analysis.

Function reference

OHLpkg 2.6.0 exposes a compact set of functions. Pick the one that matches the question you are trying to answer.

get_Seasons()

List supported seasons, IDs and season types.

get_Teams()

Retrieve team names for a supported season.

get_RawStats()

Retrieve all active skaters without a GP cutoff.

get_Stats()

Retrieve skaters with optional team and minimum-GP filters.

get_GoalieStats()

Retrieve goalie statistics with optional filters.

get_EVStats()

Calculate even-strength player production.

get_SHStats()

Retrieve short-handed production.

get_DYStats()

Identify first-time NHL draft-eligible skaters.

get_RKStats()

Retrieve players flagged as OHL rookies.

get_PlayerInfo()

Retrieve player IDs and biographical information.

get_Schedule()

Retrieve the current schedule and available results.

get_GameEvents()

Retrieve play-by-play events for an individual game.

Inside R, you can also open the package help page directly:

help(package = "OHLpkg")

?get_Stats
?get_GoalieStats
?get_GameEvents

Common problems

No players were returned

get_Stats() defaults to a minimum-games requirement. Early in a season, try min_games = 0.

I don't know the correct season or team name

get_Seasons()
get_Teams()

I received an API or connection error

OHLpkg depends on externally maintained online data feeds. Temporary outages, network restrictions or feed changes can affect availability.

Something looks wrong

Open an issue on GitHub and include the function, season, filters, package version and complete error message.
