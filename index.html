Getting started

From installation to OHL data in minutes.

Install directly from GitHub, load the package and start working with current or historical OHL seasons. The code below installs from the current GitHub main branch. Once the v2.7.0 tag is published, you can also install that specific release.

01

Install the package

Use remotes to install OHLpkg from GitHub.

02

Load OHLpkg

Attach it with the standard library() function.

03

Choose a season

Use get_Seasons() to confirm the supported names.

04

Retrieve and explore

Pick a function and filter by team or games played as needed.

install.R
# Install remotes if needed
if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}

# Install the current version from GitHub
remotes::install_github("NoahCornish/OHLpkg")

# Load and verify
library(OHLpkg)
packageVersion("OHLpkg")

# View available seasons
get_Seasons()

Online access is needed for the data feeds and official OHL player profiles. After you publish the GitHub v2.7.0 release tag, install that exact version with remotes::install_github("NoahCornish/OHLpkg@v2.7.0").

New in version 2.7.0

More complete data.
More ways to analyze.

Four new functions expand OHLpkg beyond its standardized statistics tables — from every API field to official player draft profiles.

NEW IN 2.7.0

Complete raw statistics

get_AllRawStats()

Access all available columns in the HockeyTech player-statistics feed, including faceoff, shooting and other source fields.

NEW IN 2.7.0

Player draft history

get_DraftData()

Retrieve OHL Priority, U18 Priority, CHL Import and NHL draft information, with free-agent classification and CSV export.

NEW IN 2.7.0

Power-play production

get_PPStats()

Power-play goals, assists, points, per-game production and share of total points.

NEW IN 2.7.0

Penalty-minute analysis

get_PIMStats()

Total PIM and PIM per game, with team and minimum-games filters.

Also improved: get_RawStats() now includes PlayerID and PhotoURL. Source filenames, special-teams sorting, documentation and automated tests were also updated. Read the full changelog ↗

Practical examples

Start exploring immediately.

Select an example to see the R code. Every example can be copied directly into RStudio.

raw-data.R
# Keep every column supplied by the OHL API
raw <- get_AllRawStats("2027 Season")

# Inspect available faceoff metrics
names(raw)
grep("faceoff", names(raw), value = TRUE)

# Filter by team
petes <- get_AllRawStats(
  season_name = "2027 Season",
  team = "Peterborough Petes"
)
draft-data.R
# Find draft histories for individual players
draft <- get_DraftData(
  player_id = c(9118, 9638)
)

# Look up a team's draft acquisition history
petes <- get_DraftData(
  season_name = "2027 Season",
  team = "Peterborough Petes"
)

# Export directly to CSV
write.csv(petes, "petes_draft.csv", row.names = FALSE)
special-teams.R
# Power-play production
pp <- get_PPStats(
  season_name = "2027 Season",
  min_games = 0
)

# Even-strength and short-handed production
ev <- get_EVStats("2027 Season", min_games = 0)
sh <- get_SHStats("2027 Season", min_games = 0)

# Penalty minutes per game
pim <- get_PIMStats("2027 Season", min_games = 0)
teams.R
# Get available OHL team names
get_Teams()

# Filter by a single team
london <- get_Stats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)

# Or retrieve multiple teams
rivals <- get_Stats(
  "2027 Season", min_games = 0,
  team = c("Erie Otters", "Saginaw Spirit")
)
game-events.R
# Retrieve the current schedule
schedule <- get_Schedule()

# Select a game with a recorded score
finished <- schedule[
  !is.na(schedule$HomeGoals) &
    !is.na(schedule$VisitorGoals),
]

if (nrow(finished) > 0) {
  events <- get_GameEvents(finished$ID[1])
  head(events)
}

Season naming

Why is 2026–27 called “2027 Season”?

OHLpkg labels regular seasons by their ending year. Use the exact names shown by get_Seasons() when retrieving data.

The 2026–27 regular season uses season ID 88. Individual functions handle season-name-to-ID lookup internally.

Designed responsibly

Clear results. Clear limitations.

OHLpkg makes external hockey data easier to work with while documenting differences between standardized statistics, source fields and scraped player profiles.

Tested development release

Version 2.7.0 recorded 156 passing expectations, zero failures and zero warnings. The local R CMD check also reported no errors or warnings.

Purpose-built outputs

Standardized functions return readable statistics tables, while get_AllRawStats() retains the original source column names.

Transparent source limits

Online feeds and player-profile structures can change. Draft classification includes a retrieval status; verify important entries against their profile URLs.
