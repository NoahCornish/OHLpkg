Getting started

From installation to OHL data in minutes.

OHLpkg is currently available directly from GitHub. Install it once, load it into R, and begin retrieving current or historical data.

01

Install the package

Use the remotes package to install OHLpkg from GitHub.

02

Load OHLpkg

Attach the package using the standard library function.

03

Select a season

Run get_Seasons() to view every recognized season name.

04

Retrieve your data

Choose a function and optionally filter by team or games played.

install.R 
# Install remotes if it is not already installed
install.packages("remotes")

# Install the latest version of OHLpkg
remotes::install_github(
  "NoahCornish/OHLpkg"
)

# Load the package
library(OHLpkg)

# Confirm the installed version
packageVersion("OHLpkg")

# View supported seasons
get_Seasons()
Version 2.6.0

Built for a new season.
Refined for the future.

Version 2.6.0 adds the 2026–27 OHL season while improving data validation, maintainability, documentation, and package-check compatibility.

2026–27 season support

Added “2027 Season” using OHL season ID 88, along with the latest preseason and playoff season identifiers.

Centralized season mapping

Season names and identifiers now live in one internal source, reducing duplication and simplifying future updates.

New get_Seasons()

Users can now view every season name recognized by the package before requesting data.

Safer data retrieval

API requests now provide clearer errors, validate expected fields, and handle empty datasets more gracefully.

More flexible filtering

Team and minimum-games filters make it easier to create targeted, analysis-ready datasets.

Cleaner package structure

Removed unnecessary dependencies and in-function library calls while improving documentation and R CMD check compatibility.

Function reference

One focused toolkit for working with OHL data.

Each function serves a clear purpose, from full skater datasets to individual game events.

SEASONS

get_Seasons()

Lists every supported season name and its corresponding OHL season identifier.

No arguments
SKATERS

get_RawStats()

Retrieves all active skaters without applying a minimum games-played requirement.

season_name · team
SKATERS

get_Stats()

Retrieves active skaters with optional minimum-games and team filtering.

season_name · min_games · team
GOALIES

get_GoalieStats()

Returns goalie performance statistics with flexible season, team, and games-played filters.

season_name · team · min_games
EVEN STRENGTH

get_EVStats()

Calculates even-strength goals, assists, points, rates, and scoring percentages.

season_name · team · min_games
SHORT-HANDED

get_SHStats()

Returns short-handed goals, assists, points, and related production rates.

season_name · team · min_games
PROSPECTS

get_DYStats()

Identifies first-time NHL draft-eligible skaters using dynamic birthdate ranges.

season_name · team · min_games
ROOKIES

get_RKStats()

Returns skaters identified as rookies by the official OHL data feed.

season_name · team · min_games
PLAYERS

get_PlayerInfo()

Retrieves player IDs, names, teams, birthdates, height, weight, and other profile information.

season_name · team
TEAMS

get_Teams()

Returns unique OHL teams represented in a selected season, with optional team filtering.

team · season_name
SCHEDULE

get_Schedule()

Retrieves the current 2026–27 OHL schedule, game results, teams, and game identifiers.

No arguments
PLAY-BY-PLAY

get_GameEvents()

Retrieves the play-by-play event log for an individual OHL game.

game_id
Practical examples

Start exploring immediately.

Choose an example to see how OHLpkg fits into a typical R workflow.

player-statistics.R 
# Default: players with at least 10 games played
player_stats <- get_Stats(
  season_name = "2027 Season"
)

# Include every active skater
all_players <- get_Stats(
  season_name = "2027 Season",
  min_games = 0
)

head(all_players)
team-filtering.R 
# Retrieve one team
london <- get_Stats(
  season_name = "2027 Season",
  min_games = 0,
  team = "London Knights"
)

# Retrieve multiple teams
western_teams <- get_Stats(
  season_name = "2027 Season",
  min_games = 0,
  team = c(
    "Erie Otters",
    "Saginaw Spirit"
  )
)
goalie-statistics.R 
# Retrieve every active goalie
goalies <- get_GoalieStats(
  season_name = "2027 Season",
  min_games = 0
)

# Filter by team
london_goalies <- get_GoalieStats(
  season_name = "2027 Season",
  team = "London Knights",
  min_games = 0
)
draft-eligible.R 
# Retrieve first-time draft-eligible players
draft_year <- get_DYStats(
  season_name = "2027 Season",
  min_games = 0
)

# 2027 Season eligibility range:
# September 16, 2008 to September 15, 2009

head(draft_year)
game-events.R 
# Retrieve the current OHL schedule
schedule <- get_Schedule()

# Select a game ID from the schedule
game_id <- schedule$ID[1]

# Retrieve the game's play-by-play events
events <- get_GameEvents(game_id)

head(events)
Season naming

Why is 2026–27 called “2027 Season”?

OHLpkg names regular seasons using the calendar year in which the season finishes. This keeps package inputs aligned with the season labels used by the underlying OHL data feed.

Run get_Seasons() before requesting data if you are uncertain about a season name. Inputs must match a recognized season exactly.
"2027 Season"
2026–27 regular season Season ID 88
"2026 Pre-Season"
2026 preseason Season ID 87
"2026 Playoffs"
2026 playoffs Season ID 85
"2026 Season"
2025–26 regular season Season ID 83
Designed responsibly

Clear results. Clear limitations.

OHLpkg makes external hockey data easier to use while providing safeguards against unavailable seasons and changing API fields.

Helpful validation

Incorrect season names, invalid arguments, missing fields, and unavailable data produce clear messages so users can understand what went wrong.

Analysis-ready output

Functions return familiar R data frames with readable column names, converted numeric fields, and standardized birthdates.

Focused dependencies

Version 2.6.0 removes unnecessary package dependencies and avoids attaching other libraries inside exported functions.

Transparent data source

OHLpkg retrieves information from externally operated OHL and HockeyTech data feeds. Availability and feed structure may change.
